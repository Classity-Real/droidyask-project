# Device Trees

Auto-extracted device tree sources (`.dts` / `.dtsi`) pulled from the
kernel sources built by the DroidYisky workflow.

Last updated: 2026-09-14 21:21 UTC

One top-level folder per kernel variant (GKI, CLO), mirroring the
relative path of each device tree directory in its source tree.
